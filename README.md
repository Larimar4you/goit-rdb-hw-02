# goit-rdb-hw-02

Домашнє завдання до теми 2  
**«Проектування баз даних з використанням семантичних моделей»**

## Виконані завдання

1. Нормалізація початкової таблиці до **1NF**
2. Нормалізація таблиць до **2NF**
3. Нормалізація таблиць до **3NF**
4. Створення **ER-діаграми**
5. Створення таблиць та зв'язків у **MySQL Workbench**

## Структура бази даних

База даних містить таблиці:

- `clients`
- `orders`
- `products`
- `order_details`

Зв'язки між таблицями:

- `clients` → `orders` — **1:N**
- `orders` → `order_details` — **1:N**
- `products` → `order_details` — **1:N**
